# حكيم — برنامج الحسابات

واجهة برنامج حكيم مرتبطة بقاعدة Supabase. الدخول بنفس حسابات الموظفين الحالية.

GitHub Pages: انشر الفرع main من المجلد الجذري. لا ترفع بيانات العملاء أو أكواد التهيئة أو الاستعادة.

يتضمن الإصدار المظاهر الثلاثة، واختصارات البيع والحجز والتسليم، ومتابعة مراحل الأوردر وسجل الموظف والتوقيت وروابط واتساب ويب.
